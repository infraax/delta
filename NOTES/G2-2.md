# NOTES — G2-2 Werkvensters, reservecapaciteit, BIM, contractbeheersing

## What it regulates
- Hinderaanpak: slim plannen / slim bouwen / slim reizen. Short full closures preferred over long partial ("kort en hevig"). Uniform weighing frame missing in 2021.
- Performance agreement (2005, still held in 2021): work-caused congestion on HWN ≤10% of total congestion per calendar year; reported via Rapportage Rijkswegennet.
- Proposed (not confirmed adopted): extra travel time ≤60 min; no measures <10 min; ≥75% user satisfaction, never <70%.
- Hinder classes: HWN class 3 = 10–30 min, class 4 >30 min; HVWN class 4 = 2h–2d, class 5 >2d.
- Availability is a Staat-van-de-Infra criterion and a RAMS aspect.
- SCB (since 2003): contractor assures quality via own QMS; RWS verifies the system works, not every requirement; risk-driven.
- Leidraad SE (since 2007, v3 2017): shared framework.
- Graafmelding at Kadaster ≥3 working days before machine digging.
