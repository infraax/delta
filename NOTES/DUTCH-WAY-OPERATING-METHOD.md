# NOTES — Aparatus/The Dutch Way operating method.md (1.0, v0.1)

## What it regulates
- One universal route Signal → Map → … → Learn for all Level 1–3 work.
- Gates: G0 classification, G1 preferred decision, G2 project decision, G3 acceptance. Authority: Owner or delegate; G3 also manager/maintainer.
- "No project becomes real because work has already begun."
- Handover required before acceptance; "delivery is not completion".
- Autonomy matrix: decide in mandate / speling / recalc / halt / stabilise-then-escalate.
- Maintenance types: routine, preventive, corrective, adaptive, renewal.

## Tension with RWS 2.0 core
- 1.0 runs keep (maintenance) through the same route as build. RWS 2.0 core freezes two pipelines; keep skips build gates. Recorded in OPEN.md.
- 1.0 gates omit a start gate with funding threshold and omit decharge.

## Objects (liftable)
- Gate records, handover record, change record, autonomy matrix rows.
